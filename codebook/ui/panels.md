# 1. 개요
작업자 및 검수자의 정보(이름, ID 등)를 입력받는 텍스트 입력 패널과, 현재 이미지의 검수 상태(1차, 2차 등)를 선택하는 라디오 버튼 패널을 제공하는 독립적인 Tkinter UI 위젯 모듈입니다.

# 2. 파일 간 연결 구조
- 상속 관계: `InfoPanel`과 `ReviewPanel` 모두 `tkinter.LabelFrame`을 상속받아 구현됨
- 호출 관계: 메인 레이아웃 클래스(`LayoutMixin`) 내부에서 인스턴스화되어 우측 하단 UI 구성 요소로 사용됨

# 3. 주요 상태 변수

| 클래스 | 주요 인스턴스 변수 | 역할 |
| :--- | :--- | :--- |
| **InfoPanel** | `self.vars` | 각 입력 필드(예: 이름, ID)에 입력된 값을 추적하는 `tk.StringVar` 객체들의 딕셔너리 |
| **InfoPanel** | `self._on_change` | 사용자가 텍스트를 입력하거나 지울 때마다 실시간으로 호출되는 콜백 함수 |
| **ReviewPanel** | `self.var` | 현재 선택된 검수 상태 라디오 버튼의 값을 저장하는 `tk.StringVar` |
| **ReviewPanel** | `self.buttons` | 각 상태 문자열(key)과 생성된 `tk.Radiobutton` 객체(value)를 매핑한 딕셔너리 |
| **ReviewPanel** | `self._on_change` | 사용자가 특정 검수 상태 라디오 버튼을 클릭했을 때 호출되는 콜백 함수 |

# 4. 주요 실행 흐름
- **InfoPanel (정보 입력 패널):**
  - 생성 시 전달받은 `fields` 리스트를 기반으로 동적으로 `Label`과 `Entry`(입력칸)를 생성합니다.
  - `trace_add("write", ...)` 이벤트를 바인딩하여, 타이핑이 일어날 때마다 즉각적으로 `_changed`를 트리거해 외부(메인 UI)에 변경 사실을 알립니다.
  - `is_complete()` 메서드를 통해 모든 입력칸이 공백 없이 채워졌는지 유효성을 검사합니다.
- **ReviewPanel (검수 상태 패널):**
  - 전달받은 `states` 리스트(예: 1차, 2차, review, final)를 반복문으로 순회하며 2열 그리드(`k // 2, k % 2`) 형태로 라디오 버튼을 깔끔하게 배치합니다.
  - `set_enabled()` 메서드를 제공하여, 외부 조건(`InfoPanel`의 입력 완료 여부 등)에 따라 특정 라디오 버튼의 클릭을 비활성화(`disabled`)하거나 활성화(`normal`)합니다.

# 5. 확인 및 개선 사항
- `InfoPanel`에서 입력 값의 변화를 즉시 감지(`trace_add`)하도록 설계하여, 사용자가 '이름'과 'ID'를 모두 적는 순간 '1차/2차' 등의 저장 버튼이 즉시 활성화되는 동적인 UI/UX를 완벽하게 지원합니다.
- `ReviewPanel`의 라디오 버튼에 `tristatevalue="__none__"` 속성을 적용하여, 처음 이미지를 열었을 때 아무것도 선택되지 않은(Unselected) 기본 상태를 안전하고 깔끔하게 처리합니다.
