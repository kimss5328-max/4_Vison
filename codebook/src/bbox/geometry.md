# 1. 개요
픽셀 단위의 바운딩 박스 좌표와 YOLO 모델의 정규화된 좌표 간의 상호 변환을 수행하는 순수 함수(Pure Function) 모듈입니다. Tkinter와 같은 GUI 라이브러리에 의존하지 않고 독립적으로 동작합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음

# 3. 주요 상태 변수
- 해당 없음 (상태를 저장하는 전역 변수나 클래스 멤버 변수가 없는 순수 함수로만 구성됨)

# 4. 주요 실행 흐름
이 모듈은 런타임에 호출되어 좌표를 변환하는 두 개의 함수로 구성됩니다.
- `box_to_yolo(b, iw, ih)`: 좌상단/우하단 픽셀 좌표(`x1`, `y1`, `x2`, `y2`)를 가진 딕셔너리와 이미지 크기(너비 `iw`, 높이 `ih`)를 입력받아, 이미지 크기 대비 비율로 정규화된 YOLO 좌표 중심점(`xc`, `yc`)과 너비/높이(`w`, `h`)를 튜플로 반환합니다.
- `yolo_to_box(cls, xc, yc, w, h, iw, ih)`: 클래스 ID(`cls`), 정규화된 YOLO 좌표(`xc`, `yc`, `w`, `h`), 이미지 크기(`iw`, `ih`)를 입력받아, 실제 화면이나 이미지에 그릴 수 있는 픽셀 기준의 좌표(`x1`, `y1`, `x2`, `y2`)와 클래스 정보가 담긴 딕셔너리를 반환합니다.

# 5. 확인 및 개선 사항
- 순수 함수로 작성되어 UI 로직(tkinter 등)과 완전히 분리되어 있어 재사용성 및 테스트가 용이합니다.
- `iw`(이미지 너비)나 `ih`(이미지 높이)가 0일 경우 발생할 수 있는 `ZeroDivisionError`에 대한 예외 처리가 코드 내에 없으므로, 호출하는 쪽에서 사전 검증이 필요할 수 있습니다.
