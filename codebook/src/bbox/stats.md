# 1. 개요
이미지별 작업 정보 목록(entry)을 입력받아 검수 단계별 개수, Scene Type 분포, 클래스별 BBox 수, 그리고 이슈 기록 및 빈 라벨 등의 품질 지표를 순수 계산(개수 및 비율 산출)하는 통계 로직 모듈입니다. 화면 UI나 파일 입출력과 완전히 분리되어 비즈니스 계산 및 데이터 가공만을 담당합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (독립 계산 모듈)
- 외부 의존성 및 호출 관계: `src.config`의 `STATS_STAGES`, `SCENE_TYPES` 상수를 참조하며, `src.validation.rules`의 `class_ids`, `class_name` 함수를 활용함

# 3. 주요 상태 변수 및 함수

| 분류 | 함수 / 유틸리티 | 역할 |
| :--- | :--- | :--- |
| **비율 계산** | `pct(n, total)` | 전체 개수(`total`) 대비 특정 개수(`n`)의 백분율 비율을 안전하게 계산 |
| **종합 요약** | `summarize(entries)` | 이미지별 엔트리 리스트를 순회하며 단계별, 씬별, 클래스별 빈도 및 품질 지표(전체 BBox, 빈 라벨, 이슈 등)를 집계하여 통계 딕셔너리로 반환 |
| **표 데이터 생성** | `table_rows(s)`, `stage_table_rows(s)` | 요약된 통계 데이터(`s`)를 기반으로 UI 표나 리포트에 즉시 바인딩할 수 있는 `[(항목, 값, 비율)]` 형태의 행 리스트 생성 |
| **CSV 포맷팅** | `csv_rows(s, scope)` | 통계 데이터를 CSV 저장용 구조(`[구분, 항목, 값, 비율]`)로 변환 |

# 4. 주요 실행 흐름
- **데이터 집계 (`summarize`):**
  - 입력된 `entries` 리스트를 순회하면서 작업 상태(`stage`), 씬 타입(`scene`), BBox 개수, 빈 라벨(`empty`), 이슈 유무(`issues`), 그리고 개별 클래스 ID(`classes`)를 누적 집계합니다.
  - 정의되지 않은 클래스는 `unknown_cls`로 별도 분류하여 품질 예외 상황을 추적할 수 있도록 합니다.
- **표 및 CSV 행 변환 (`table_rows`, `stage_table_rows`, `csv_rows`):**
  - 계산된 통계 수치에 `pct()` 함수를 적용하여 각 항목별 백분율 문자열을 함께 조합함으로써, 화면 출력용 및 파일 저장용 표 데이터를 체계적으로 빌드합니다.

# 5. 확인 및 개선 사항
- GUI 라이브러리나 파일 I/O에 의존하지 않는 순수 함수(Pure Function)들로만 구성되어 있어 단위 테스트(Unit Test) 작성과 유지보수가 매우 용이합니다.
