# 1. 개요
프로젝트 폴더를 열 때 원본 이미지와 YOLO 라벨 데이터셋의 무결성 및 정합성을 백그라운드에서 기계적으로 자동 검사하는 유효성 검증(Auto-Validator) 모듈입니다. GUI(Tkinter) 의존성이 전혀 없어 백그라운드 스레드에서 안전하게 실행되며, 규칙 검사 결과는 `reports/validation_report.csv`에 누적 기록되고 팝업 및 상태바용 요약 리포트를 생성합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (독립 실행형 검증 및 리포트 함수 모듈)
- 외부 의존성 및 호출 관계: 
  - `src.config`의 `BASE_DIR` 상수 참조
  - `src.validation.rules`의 클래스 유효성 검사 함수(`is_known`, `is_selectable`, `class_name`, `replacement`) 연동
  - `FolderMixin`의 백그라운드 스레드 및 `root.after` 풀링 메커니즘에서 호출됨

# 3. 주요 상태 변수 및 핵심 함수

| 분류 | 함수 / 상수 | 역할 |
| :--- | :--- | :--- |
| **파일 검사** | `check_image`, `check_class`, `check_label` | 개별 이미지 파일의 존재 및 해상도 유효성, YOLO 라벨 텍스트의 포맷/좌표 범위(`0~1`) 및 클래스 정의 일치 여부 검사 |
| **작업 검증** | `run_validation(job)` | 프로젝트별 이미지-라벨 쌍(`pairs`)과 고아 라벨(`orphans`)을 대상으로 검사를 수행하고 결과를 이슈 리스트로 반환 |
| **리포트 기록** | `write_report` | 검사 결과를 `reports/validation_report.csv`에 CSV 형태로 누적 추가 (기록이 없으면 'OK' 레코드 남김) |
| **결과 요약** | `summarize`, `print_console` | 에러/경고/리뷰 등 등급별 건수를 집계하여 사용자 안내용 팝업 문구와 상태 표시줄 메시지 생성 |

# 4. 주요 실행 흐름
- **개별 파일 무결성 진단 (`check_image`, `check_label`):**
  - 이미지 파일을 PIL로 열어 유효한 픽셀 크기를 가졌는지 확인하고, 라벨 텍스트 파일을 줄 단위로 읽어 YOLO 포맷(`5개 값`, `0~1 사이의 정규화 좌표`, `w, h > 0`)을 검증합니다.
- **클래스 정책 판정 (`check_class`):**
  - `rules.py` 규칙을 바탕으로 정의되지 않은 클래스 번호는 `ERROR`, 고무장갑 등 지정 불가 클래스는 대체 번호 안내와 함께 `REVIEW` 등급으로 분류합니다.
- **백그라운드 실행 및 결과 집계 (`run_validation`, `summarize`):**
  - 앱 로드 시 백그라운드 스레드에서 각 프로젝트를 순회하며 검사를 마치고, `reports/validation_report.csv`에 상세 이력을 기록한 뒤 메인 스레드로 결과를 전달하여 경고 또는 정보 팝업을 띄웁니다.

# 5. 확인 및 개선 사항
- GUI와 완전히 분리된 순수 로직으로 구현되어 백그라운드 스레드에서 안전하게 동작하며 대용량 데이터셋 검사 시에도 UI 멈춤 현상이 없습니다.
- 이상이 없는 경우에도 'OK' 기록을 명시적으로 남겨 검사 수행 이력이 투명하게 관리되도록 설계되었습니다.
