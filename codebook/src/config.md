# 1. 개요
프로그램 전역에서 사용되는 핵심 설정 상수 및 메타데이터(경로, 결과 구조, 클래스 정의, 사용자 목록, 검수 상태, 색상, 폰트 등)를 중앙 집중식으로 정의한 환경 설정 모듈입니다. 모든 주요 비즈니스 규칙과 파라미터가 이 파일에 모여 있어 전역적인 수정 및 유지보수가 용이합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (독립 설정 모듈)
- 외부 의존성 및 호출 관계: 프로젝트 내 거의 모든 Mixin, UI 패널, 데이터 검증 및 저장 모듈(`config` 참조)에서 공통으로 임포트하여 사용됨

# 3. 주요 상태 변수 및 설정 그룹

| 분류 | 주요 상수명 | 역할 |
| :--- | :--- | :--- |
| **경로 및 디렉토리** | `BASE_DIR`, `RESULT_DIR`, `STAGE_DIRS`, `MANIFEST_FILE` | 프로그램 루트 경로, 데이터셋별 결과 디렉토리 명칭, 단계별 하위 폴더 구조, 전역 데이터 대장 파일명 정의 |
| **데이터 대장 스키마** | `MANIFEST_HEADER`, `STAGE_STATUS`, `SCENE_TYPES`, `REVIEW_REASONS` | `dataset_manifest.csv`의 열 구성, 단계별 상태 및 QA 매핑 규칙, 이미지 씬 유형 및 리뷰 사유 목록 |
| **클래스 및 사용자** | `CLASSES`, `CLASS_NAMES`, `PEOPLE`, `ROLE_NAMES`, `STAGES` | YOLO 모델 학습 클래스 정의 및 표시 이름, 작업자/검수자 인물 정보, 검수 상태 단계 목록 |
| **통계 및 UI 스타일** | `STATS_STAGES`, `COLORS`, `FONT`, `PREVIEW_FONTS` | 통계 화면용 작업 상태별 색상 및 폰트, 바운딩 박스 컬러 팔레트, 렌더링용 폰트 경로 목록 |

# 4. 주요 실행 흐름
- **전역 설정 초기화 및 관리:**
  - 모듈 로드 시 운영체제 환경에 맞춰 프로그램 루트 경로(`BASE_DIR`)와 설정 파일 저장 경로(`SETTINGS_PATH`)를 계산합니다.
  - 데이터셋별 결과 폴더 접미사(`_result`)와 단계별 디렉토리 매핑(`STAGE_DIRS`)을 구성하여, 원본 데이터를 훼손하지 않고 결과물을 독립된 디렉토리에 체계적으로 적재할 수 있도록 지원합니다.
- **클래스 및 권한 규칙 매핑:**
  - `CLASSES` 리스트를 기반으로 정렬된 클래스 이름 목록(`CLASS_NAMES`)을 자동 생성하며, 작업자(`WORKER_TARGETS`)와 검수자(`REVIEWER_TARGETS`) 간의 허용 작업 단계를 분리하여 권한 검증의 기반을 제공합니다.

# 5. 확인 및 개선 사항
- 프로젝트 전반에서 사용되는 매직 넘버와 문자열 상수를 한곳에 모아 관리함으로써 코드의 일관성과 가독성을 크게 높였습니다.
- 윈도우 및 리눅스(WSL 등) 환경별 한글 폰트 경로(`PREVIEW_FONTS`)를 다중 예외 처리 형태로 미리 정의하여 크로스 플랫폼 호환성을 확보했습니다.
