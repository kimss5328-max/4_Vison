# 1. 개요
Tkinter 캔버스 위에서 마우스 드래그를 통한 바운딩 박스 생성(`draw`), 기존 박스 선택(`press`), 4방향 핸들을 이용한 크기 조절(`resize`), 캔버스 패닝(`pan`) 및 휠 확대·축소(`on_wheel`)를 처리하는 핵심 인터랙션 Mixin 클래스입니다. 아울러 클래스 지정 및 보류 박스 정리(`discard_pending`), 선택 박스 삭제, 그리고 `labelList`/`labelDetail`을 통한 객체별 크기 정보 및 상세 스펙 갱신을 전담합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (GUI 메인 클래스에 다중 상속되어 `EditMixin` 형태로 사용됨)
- 외부 의존성 및 호출 관계: `src.config`의 상수(`ISSUE_ID`, `PENDING_COLOR`, `HANDLE_R`, `MIN_BOX_PX`, `WHEEL_STEP` 등)를 참조하며, `src.validation.rules`의 유효성 검사 및 안내 메시지 함수와 연동됨

# 3. 주요 상태 변수 및 마우스 모드

| 분류 | 주요 인스턴스 변수 | 역할 |
| :--- | :--- | :--- |
| **인터랙션 모드** | `self.mode` | 현재 마우스 동작 상태 (`None`, `"press"`, `"draw"`, `"pan"`, `"resize"`, `"zoomsel"`) |
| **좌표 및 객체 제어** | `self.press_xy`, `self.temp_rect` | 마우스가 눌린 시작 좌표 및 드래그 중 그려지는 가이드 렉트(Rectangle) 캔버스 ID |
| **선택 및 보류** | `self.selected`, `self.pending` | 현재 선택된 바운딩 박스 객체 리스트 및 클래스가 아직 지정되지 않은 보류 중인 박스 |
| **조절 핸들** | `self.resize_hd`, `self._cursor` | 크기 조절 중인 핸들 위치 방향(ex: `"nw"`, `"se"`) 및 캔버스 커서 상태 캐시 |

# 4. 주요 실행 흐름
- **마우스 이벤트 제어 (`on_press`, `on_drag`, `on_release`):**
  - 바운딩 박스의 모서리 핸들 영역(`handle_at`)을 누른 경우 크기 조절 모드(`resize`)로 진입합니다.
  - `Shift` 키 조합 시 캔버스 패닝(`pan`), `Ctrl` 키 조합 시 다중 박스 선택/해제 토글이 동작합니다.
  - 빈 영역을 드래그하면 새 바운딩 박스 그리기(`draw`) 모드가 활성화되며, 최소 크기(`MIN_BOX_PX`) 이상일 때 보류 상태(`pending`)의 박스로 등록됩니다.
- **마우스 휠 줌 (`on_wheel`):**
  - 마우스 포인터 위치를 기준으로 휠 업/다운 방향에 따라 `WHEEL_STEP` 비율로 캔버스를 확대·축소합니다.
- **클래스 지정 및 삭제 (`on_class_select`, `delete_selected`):**
  - 우측 클래스 목록에서 항목을 선택하면 보류 중인 박스나 선택된 박스들에 클래스 번호(`cls`)를 부여하고 `auto=False`로 확정합니다.
  - 박스 삭제 시 사용자 확인 다이얼로그를 거쳐 리스트에서 안전하게 제거하고 즉시 작업 중 임시 저장(`autosave_work`)을 트리거합니다.
- **정보 패널 동기화 (`refresh_info`, `update_detail`, `on_tree_select`):**
  - 캔버스 상의 박스 변경 사항을 `labelList`(Treeview)와 상세 정보 패널에 YOLO 정규화 좌표 형식(`xc, yc, w, h`)으로 실시간 반영합니다.

# 5. 확인 및 개선 사항
- 크기 조절이나 박스 삭제, 클래스 지정 등 데이터 변경이 일어날 때마다 `autosave_work()`를 자연스럽게 호출하여 예기치 않은 종료 상황에서도 작업 내용이 안전하게 보호됩니다.
- 미지정 클래스 박스(`pending`)가 선택된 상태에서 다른 곳을 누르거나 이탈할 때 자동으로 정리되는 가이드 로직이 견고하게 갖추어져 있습니다.
