# 1. 개요
단계 보기에서 '그래프'를 선택했을 때 중앙 이미지 렌더링 영역 대신 전환되어 표시되는 시각화 및 통계 화면 관리 Mixin 클래스입니다. Tkinter Canvas를 이용해 추가 라이브러리 설치 없이 작업 상태별 분포를 도넛 차트로 렌더링하고, 품질 지표 표(`Treeview`)와 동적 범위 선택(볼 단계) 체크박스를 제공하며, 최종 집계 결과의 CSV 저장 기능을 전담합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (GUI 메인 클래스에 다중 상속되어 `StatsMixin` 형태로 사용됨)
- 외부 의존성 및 호출 관계: 
  - `src.config`의 통계용 폰트, 도넛 크기, 작업 상태 색상 상수 참조
  - `src.bbox.stats` 모듈의 `summarize`, `stage_table_rows`, `csv_rows`를 통해 데이터 집계 수행
  - `src.bbox.manifest`를 통해 매니페스트(`dataset_manifest.csv`) 메타데이터 연동

# 3. 주요 상태 변수 및 시각화 구성

| 분류 | 주요 인스턴스 변수 | 역할 |
| :--- | :--- | :--- |
| **통계 화면 위젯** | `self.statsFrame`, `self.statsStageCanvas`, `self.statsTable` | 통계 화면을 감싸는 메인 프레임, 도넛 차트 렌더링용 캔버스, 품질 지표 출력용 트리뷰 |
| **범위 제어** | `self.scopeRow`, `self.scope_vars`, `self.scope_all` | 단계별 집계 포함 여부를 제어하는 체크박스 집합 및 전체 선택 상태 변수 |
| **상태 캐시** | `self.stats_on`, `self._stats` | 통계 화면 활성화 여부 플래그 및 최근 계산된 통계 요약 데이터 딕셔너리 캐시 |

# 4. 주요 실행 흐름
- **통계 화면 토글 (`show_stats`, `hide_stats`):**
  - 단계 보기 드롭다운에서 '그래프'를 고르면 기존 이미지 캔버스를 숨기고(`grid_remove`) 통계 프레임을 활성화(`grid`)한 뒤 실시간으로 데이터를 집계(`refresh_stats`)합니다.
- **범위 선택 및 동적 집계 (`_build_scope_checks`, `refresh_stats`):**
  - 사용자가 체크한 단계(미작업, pass, edited, review, view, final 등)에 해당하는 이미지들만 필터링하여 `stats.summarize`에 전달하고, 그 결과를 테이블과 차트에 반영합니다.
- **도넛 차트 렌더링 (`_draw_donut`):**
  - 작업 상태별 비율을 계산하여 Tkinter 캔버스에 파이/아크 조각을 그리고, 일정 비율 이상인 조각에 퍼센트 라벨을 표기하며 가운데 구멍에 총 수량을 깔끔하게 표시합니다.
- **CSV 리포트 내보내기 (`save_stats_csv`):**
  - 현재 집계된 통계 데이터를 타임스탬프 기반 파일명으로 `reports/stats_<날짜시각>.csv` 경로에 안전하게 기록합니다.
