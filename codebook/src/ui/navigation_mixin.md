# 1. 개요
현재 선택된 이미지 파일 열기 및 프리페치(`prefetch`), 이전/다음 이미지로의 순차 탐색 이동 네비게이션, 이미지별 이슈 노트(메모) 관리, 그리고 `workflow` 모듈과 연동된 단계 흐름 및 수정 권한(`refresh_workflow`, `check_edit`) 검증을 전담하는 내비게이션 Mixin 클래스입니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (GUI 메인 클래스에 다중 상속되어 `NavigationMixin` 형태로 사용됨)
- 외부 의존성 및 호출 관계: 
  - `src.config`의 `STAGES`, `ROLE_NAMES`, `SOURCE_LABEL` 상수 참조
  - `src.validation.rules`의 `describe_locked` 함수를 통한 잠긴 클래스 안내
  - `src.bbox.workflow`의 `person_by_label`을 통한 작업자/검수자 권한 매핑

# 3. 주요 상태 변수 및 핵심 메서드

| 분류 | 함수 / 메서드 | 역할 |
| :--- | :--- | :--- |
| **현재 경로 및 박스** | `cur_path`, `cur_boxes` | 현재 활성화된 이미지 파일 경로 반환 및 소속 바운딩 박스 리스트 추출 |
| **메모 및 노트 관리** | `save_current_note` | 현재 화면에 입력된 이슈 노트 내용을 메모리 딕셔너리에 실시간 동기화 |
| **권한 및 워크플로우** | `current_person`, `update_review_buttons`, `refresh_workflow` | 선택된 작업자/검수자 프로필을 기반으로 허용된 검수 단계(`stages`)와 수정 가능 여부(`edit_ok`)를 재판정 |
| **이미지 열기 및 렌더링** | `show_image`, `clear_view` | PIL을 통해 이미지를 RGB로 로드하고, 캐시 검사, 자동 추론 결과 연동, 화면 상태 갱신 수행 |
| **비동기 프리페치** | `prefetch` | 다음 순번의 이미지를 백그라운드 스레드로 미리 로드하여 이미지 전환 속도 최적화 |
| **네비게이션 이동** | `prev_image`, `next_image` | 인덱스를 증감하며 이전/다음 이미지로 이동하고 진행률 세트(`passed`) 업데이트 |

# 4. 주요 실행 흐름
- **워크플로우 및 권한 동기화 (`refresh_workflow`):**
  - 현재 이미지의 이력 및 상태 흐름 객체(`Flow`)를 가져와 선택된 사용자 역할에 따른 편집 가능 여부(`can_act`)를 판정합니다.
  - 검수 상태 패널의 활성화 상태와 기본 타겟을 갱신하고, 상단 히스토리 패널에 단계별 이력을 출력합니다.
- **이미지 로드 및 자동 추론 연동 (`show_image`):**
  - 이미지 파일 로드 시 _cache 딕셔너리를 확인하거나 새로 읽어들이며, 저장된 어노테이션이나 메모가 없을 경우 `autoOnOpen` 옵션에 따라 비동기 자동 YOLO 추론을 시도합니다.
  - 상태 표시줄에 이미지 해상도, 남은 개수, 자동 BBox 개수, 잠긴 클래스 경고, 임시 저장 여부 등을 종합하여 직관적인 안내 메시지를 출력합니다.
- **백그라운드 프리페치 (`prefetch`):**
  - 사용자가 현재 이미지를 보는 동안 다음 순번 이미지(`j = i + 1`)를 백그라운드 댸몬 스레드로 미리 열어 메모리 캐시에 적재함으로써 즉각적인 페이지 전환을 보장합니다.

# 5. 확인 및 개선 사항
- 이미지 전환 시마다 메모와 보류 중인 박스 상태가 안전하게 저장 및 정리되며, 권한에 맞지 않는 작업 시 즉시 가이드 문구를 띄워 사용자 오작동을 방지합니다.
- 대용량 이미지 탐색 시 뚝뚝 끊기는 현상을 방지하기 위한 프리페치 스레딩 기법이 효율적으로 구현되어 있습니다.
