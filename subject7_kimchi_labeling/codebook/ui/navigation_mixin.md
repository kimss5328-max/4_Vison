# 1. 개요
현재 이미지 열기, 이전/다음 이미지 이동, 이미지별 메모(이슈 노트 및 검수 상태) 관리, 그리고 성능 향상을 위한 다음 이미지 백그라운드 프리패치(Prefetch) 기능을 제공하는 Mixin 클래스입니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (GUI 메인 클래스 등에 다중 상속되어 `NavigationMixin` 형태로 사용됨)

# 3. 주요 상태 변수

| 분류 | 주요 인스턴스 변수 | 역할 |
| :--- | :--- | :--- |
| **인덱스/캐시** | `self.idx` | `self.images` 리스트 내에서 현재 화면에 띄워진 이미지의 인덱스 |
| **인덱스/캐시** | `self._cache` | `prefetch`를 통해 미리 로드해 둔 다음 순서의 `PIL.Image` 객체를 담는 캐시 딕셔너리 |
| **상태 저장** | `self.last_stage` | 직전에 선택했던 검수 상태를 기억하여, 다음 이미지 이동 시 기본값으로 적용 |
| **데이터 관리** | `self.notes` | 이미지 경로(`p`)를 키로 하여 입력된 이슈 노트를 임시 보관하는 딕셔너리 |
| **데이터 관리** | `self.review_status` | 이미지 경로(`p`)를 키로 하여 선택된 검수 상태(1차, 2차 등)를 저장하는 딕셔너리 |

# 4. 주요 실행 흐름
- **이미지 로드 및 초기화 (`show_image`):**
  - 전환 전 기존 이미지의 작성 중인 메모를 저장하고 임시 박스를 취소(`discard_pending`)합니다.
  - 미리 캐싱된 이미지(`_cache`)가 있으면 즉시 사용하고, 없으면 디스크에서 새로 엽니다(`Image.open`).
  - 과거에 저장한 라벨/노트 정보를 불러옵니다. 라벨이 없는 새 이미지이고 자동 추론이 켜져(`autoOnOpen`) 있다면, YOLO 모델을 돌려 자동 바운딩 박스를 씌웁니다.
  - 캔버스의 줌을 초기화(`fit_view`)하고, 상태 표시줄 메세지를 갱신한 뒤, 다음 이미지 로딩을 백그라운드로 지시(`prefetch`)합니다.
- **다음 이미지 프리패치 (`prefetch`):**
  - 파이썬의 `threading.Thread`를 사용하여 메인 UI를 멈추지 않고 다음 이미지(`j`)를 백그라운드에서 읽어 `_cache`에 올려둡니다.
- **이미지 이동 (`prev_image`, `next_image`):**
  - 인덱스 연산을 통해 이전/다음 이미지로 전환하며, 지나간 이미지는 `self.passed` 세트에 추가하고 진행률 막대를 갱신(`update_progress`)합니다.
- **검수 상태 활성화 제어 (`stage_allowed`, `update_review_buttons`):**
  - 작업자 정보 패널(`workerInfo`) 또는 검수자 정보 패널(`reviewerInfo`)의 입력 완료 상태(`is_complete()`)에 따라 검수 라디오 버튼의 활성화/비활성화 상태를 실시간으로 동기화합니다.

# 5. 확인 및 개선 사항
- 이미지 이동 시 백그라운드 스레드를 이용한 `prefetch` 기법이 적용되어 있어 대용량 이미지 셋에서도 로딩 체감 속도를 크게 줄이도록 잘 설계되어 있습니다.
- 이미지를 열 때 `UNUSED_CLASS`(예: 4번 클래스)가 박스에 포함되어 있거나 아직 저장 전(작업 중)인 경우, 하단 상태 표시줄(Status bar)에 알림 및 경고 메시지를 명확히 표시하여 작업자 실수를 방지합니다.
