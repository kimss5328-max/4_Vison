# 1. 개요
이미지 캔버스상의 좌표계와 실제 이미지의 픽셀 좌표계 간의 변환, 마우스 상호작용에 따른 뷰 확대/축소 및 이동(Panning), 그리고 캔버스 위 이미지 렌더링과 바운딩 박스/조절 핸들 시각화를 전담하는 Mixin 클래스입니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (GUI 메인 클래스에 다중 상속되어 `ViewMixin` 형태로 사용됨)
- 외부 모듈 의존성: `src.bbox.geometry` 모듈의 순수 함수(`box_to_yolo`, `yolo_to_box`)를 호출하여 좌표 변환 수행

# 3. 주요 상태 변수

| 분류 | 주요 인스턴스 변수 | 역할 |
| :--- | :--- | :--- |
| **비율 및 위치** | `self.scale`, `self.fit_scale` | 현재 이미지의 확대/축소 배율 및 화면에 꼭 맞춘 기본 배율 |
| **비율 및 위치** | `self.ox`, `self.oy` | 캔버스 상에서 이미지 그려지는 시작점의 X, Y 오프셋 좌표 |
| **상태 플래그** | `self.is_fit`, `self.zoom_mode` | 현재 화면 맞춤 상태 여부 및 드래그 영역 확대 모드 활성화 여부 |
| **렌더링 캐시** | `self.tkimg` | 캔버스에 표시하기 위해 변환된 `ImageTk.PhotoImage` 객체 |
| **히트 테스트** | `self._label_hits` | 화면에 그려진 박스 이름표의 영역(`tb`)과 박스 객체(`b`)의 매핑 리스트 |

# 4. 주요 실행 흐름
- **좌표 변환 (`to_canvas`, `to_image`):**
  - 이미지 픽셀 좌표를 현재 줌 레벨과 오프셋을 반영하여 캔버스 좌표로 변환하거나, 반대로 마우스 포인터의 캔버스 위치를 이미지 내부 좌표로 환산합니다.
- **확대·축소 및 이동 제어 (`fit_view`, `zoom_at`, `clamp_view`):**
  - 창 크기 변화나 휠 스크롤에 맞춰 이미지를 확대/축소하고, 이미지 가장자리가 캔버스를 벗어나지 않도록 `clamp_view`를 통해 오프셋을 제한합니다.
- **이미지 및 박스 렌더링 (`render`, `draw_boxes`):**
  - 현재 보이는 영역(`visible_rect`)만큼 이미지를 잘라내어 해상도 저하를 방지하고 속도를 최적화한 뒤 캔버스에 그립니다.
  - `draw_boxes`를 통해 각 바운딩 박스의 클래스별 색상, 점선 여부(미지정, 이슈, AI 자동 예측 등), 크기 조절 핸들, 그리고 텍스트 이름표와 배경색을 함께 렌더링합니다.
- **히트 테스트 (`hit_test`):**
  - 마우스 클릭 시 이름표 영역을 우선 검사하고, 이어 박스 내부 좌표를 판정하여 겹쳐 있는 박스 중 가장 작은 크기의 박스를 정확히 선택하도록 처리합니다.

# 5. 확인 및 개선 사항
- 이미지 영역을 크롭하여 렌더링할 때 확대 배율(`s >= 3`)에 따라 `Image.NEAREST`와 `Image.BILINEAR`를 다르게 적용하여 도트 밀도와 성능을 모두 고려하도록 설계되었습니다.
