# 1. 개요
이미지 캔버스 위에서 마우스를 이용한 바운딩 박스 그리기, 선택, 크기 조절, 화면 이동(Pan), 마우스 휠 확대/축소, 클래스 할당 및 박스 삭제, 화면 우측의 박스 정보 패널 업데이트 기능을 전담하는 Mixin 클래스입니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (GUI 메인 클래스에 다중 상속되어 사용되는 `EditMixin` 형태)

# 3. 주요 상태 변수

| 분류 | 주요 변수 | 역할 |
| :--- | :--- | :--- |
| **모드 관리** | `self.mode` | 현재 마우스 동작 상태 (`"resize"`, `"pan"`, `"zoomsel"`, `"press"`, `"draw"`, `None` 등) |
| **박스 상태** | `self.selected` | 현재 선택된 바운딩 박스들의 리스트 (Ctrl+클릭 시 다중 선택 가능) |
| **박스 상태** | `self.pending` | 드래그하여 새로 그렸으나, 아직 클래스가 지정되지 않아 대기 중인 임시 박스 |
| **마우스/조작** | `self.press_xy` | 마우스 클릭(Press)이 시작된 최초 x, y 좌표 |
| **마우스/조작** | `self.resize_hd` | 크기 조절 시 마우스로 잡고 있는 모서리 핸들의 위치 (`"nw"`, `"ne"`, `"sw"`, `"se"`) |
| **UI 객체** | `self.temp_rect` | 캔버스에 그려지고 있는 임시 점선 사각형의 캔버스 ID |

# 4. 주요 실행 흐름
- **마우스 이벤트 (`on_press`, `on_drag`, `on_release`):** 
  - 클릭 위치와 누른 키(Shift, Ctrl)에 따라 모서리 핸들 조절, 화면 이동(Pan), 다중 선택, 임시 박스 그리기 등을 분기하여 처리합니다.
  - 마우스를 놓을 때 박스 그리기가 완료되면 박스는 `pending` 상태가 되며, 사용자에게 클래스 선택을 유도합니다.
- **클래스 할당 및 삭제 (`on_class_select`, `discard_pending`, `delete_selected`):**
  - 대기 중이거나 선택된 박스에 우측 목록의 클래스를 지정하면 좌표와 클래스가 확정되며 자동 저장(`autosave_work`)이 트리거됩니다.
  - 임시 박스(`pending`) 상태에서 클래스를 지정하지 않고 다른 작업을 시도하면 해당 박스는 자동 삭제됩니다.
- **화면 제어 (`on_motion`, `on_wheel`):**
  - 마우스 위치에 따라 커서 아이콘을 변경하며, 휠 스크롤 시 마우스 포인터를 중심으로 이미지를 확대/축소(`WHEEL_STEP`)합니다.
- **정보 패널 동기화 (`refresh_info`, `update_detail`, `on_tree_select`):**
  - 캔버스에서 일어난 박스의 추가/삭제/크기 변경 사항을 우측 TreeView(목록)와 하단 상세 정보 패널(YOLO 좌표 값)에 즉시 갱신하고 동기화합니다.

# 5. 확인 및 개선 사항
- 사용자가 직접 박스를 그리거나 크기를 조절, 클래스를 지정하는 등의 행동을 하면 `b["auto"] = False` 처리가 되어 모델이 예측한 자동 박스와 명확히 구분됩니다.
- 박스의 좌표 변경 및 클래스 할당이 이루어질 때마다 `self.autosave_work()`를 호출하여 작업 유실을 방지하도록 `StorageMixin`의 메서드와 긴밀하게 연동되어 있습니다.
