# 1. 개요
Tkinter GUI 라이브러리의 기초를 학습하기 위한 예제 스크립트로, 메인 윈도우 생성, 레이블(Label)과 버튼(Button) 위젯 배치, 그리고 버튼 클릭 시 발생하는 이벤트 콜백(`change_message`)을 통해 UI 상태를 동적으로 변경하는 간단한 프로그램을 제공합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (단일 독립 실행형 스크립트)
- 라이브러리 의존성: Python 표준 GUI 라이브러리인 `tkinter`를 임포트하여 사용

# 3. 주요 상태 변수 및 객체

| 분류 | 객체명 / 변수 | 역할 |
| :--- | :--- | :--- |
| **윈도우** | `root` | Tkinter 메인 애플리케이션 윈도우 인스턴스 (`tk.Tk`) |
| **위젯** | `title_label` | 상단에 대제목을 표시하는 `tk.Label` 위젯 |
| **위젯** | `message_label` | 상태 메시지를 표시하며 버튼 클릭 시 텍스트가 갱신되는 `tk.Label` 위젯 |
| **위젯** | `change_button` | 클릭 시 `change_message` 함수를 호출하는 `tk.Button` 위젯 |

# 4. 주요 실행 흐름
- **메인 윈도우 초기화:**
  - `tk.Tk()`로 루트 창을 생성하고 제목(`"예제 1 - Tkinter 기본 화면"`)과 크기(`500x300`)를 설정합니다.
- **위젯 배치 (Pack):**
  - 제목 레이블(`title_label`), 안내 메시지 레이블(`message_label`), 메시지 변경 버튼(`change_button`)을 위에서 아래로 순차적으로 배치(`pack`과 `pady` 활용)합니다.
- **이벤트 처리 (`change_message`):**
  - 사용자가 버튼을 클릭하면 `change_message` 함수가 호출되며, `message_label.config(text=...)`를 통해 레이블의 텍스트가 `"버튼을 눌렀습니다!"`로 즉시 변경됩니다.
- **이벤트 루프 실행:**
  - `root.mainloop()`를 호출하여 사용자의 입력(마우스 클릭 등)을 대기하며 창이 유지되도록 실행 상태를 유지합니다.
