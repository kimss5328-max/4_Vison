# 1. 개요
현재 실행 중인 Python 환경의 버전과 핵심 딥러닝 라이브러리(`PyTorch`, `Ultralytics`)의 버전 정보, 그리고 GPU(CUDA) 가속 사용 가능 여부와 장치명을 콘솔에 출력하여 개발 환경을 점검하는 진단용 스크립트입니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (단일 독립 실행형 진단 스크립트)
- 라이브러리 의존성: `sys`, `torch`, `ultralytics` 모듈을 임포트하여 사용

# 3. 주요 상태 변수 및 함수

| 분류 | 함수 / 객체 | 역할 |
| :--- | :--- | :--- |
| **진단 함수** | `main()` | Python, PyTorch, Ultralytics 버전 정보와 CUDA 가속 상태를 순차적으로 확인 및 출력 |
| **시스템 정보** | `sys.version` | 현재 구동 중인 파이썬의 메이저·마이너 버전 문자열 추출 |
| **PyTorch 정보**| `torch.__version__`, `torch.cuda` | PyTorch 설치 버전 확인 및 CUDA 디바이스 가용성 검사 |

# 4. 주요 실행 흐름
- **환경 정보 출력:**
  - `sys.version.split()[0]`을 통해 파이썬 버전을 간결하게 출력합니다.
  - `torch.__version__`과 `ultralytics.__version__`을 출력하여 패키지 버전 정합성을 확인합니다.
- **CUDA 가속 확인:**
  - `torch.cuda.is_available()`을 호출하여 NVIDIA GPU 및 드라이버가 정상적으로 연동되었는지 확인합니다.
  - 사용 가능한 경우 `torch.cuda.get_device_name(0)`을 통해 첫 번째 GPU의 모델명을 출력합니다.
- **진입점 실행:**
  - 스크립트가 직접 실행될 경우(`if __name__ == "__main__":`) `main()` 함수를 호출하여 진단을 수행합니다.
