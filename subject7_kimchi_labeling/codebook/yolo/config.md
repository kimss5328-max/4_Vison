# 1. 개요
라벨링 프로그램 전체에서 공통으로 사용되는 전역 상수 및 설정 값들을 정의한 모듈입니다. 디렉토리 경로, 결과 저장 구조, 클래스 명칭 및 ID, 검수 단계, 색상 팔레트, 폰트 종류, 그리고 마우스 조작 관련 파라미터들을 중앙 집중식으로 관리합니다.

# 2. 파일 간 연결 구조
- 상속 관계: 없음 (독립 설정 모듈)
- 호출 관계: 본 모듈의 상수(`BASE_DIR`, `CLASS_NAMES`, `STAGES`, `COLORS`, `FONT` 등)는 GUI 레이아웃, Mixin 클래스, 검증 모듈, 그리고 메인 애플리케이션(`LabelingApp`) 전반에 걸쳐 임포트되어 사용됨

# 3. 주요 상태 변수 (상수 그룹)

| 분류 | 주요 상수 명칭 | 역할 및 설명 |
| :--- | :--- | :--- |
| **경로 설정** | `BASE_DIR`, `PICK_START_DIR`, `SETTINGS_PATH` | 프로그램 기준 루트 경로, 폴더 선택 창의 초기 디렉토리, 마지막 작업 폴더 기억을 위한 JSON 설정 파일 경로 |
| **결과 디렉토리** | `RAW_DIR`, `ISSUES_DIR`, `CSV_DIR`, `STAGE_DIRS` | 원본 사본, 이슈 노트, 이력 CSV 및 각 검수 단계별(`1차`, `2차`, `review`, `final`) 저장 폴더 구조 정의 |
| **클래스 정의** | `CLASS_NAMES`, `CLASS_IDS`, `UNUSED_CLASS` | 이물 감지 클래스 목록(0~6번) 및 4번('고무장갑')의 사용 안 함 처리(`UNUSED_CLASS`) 관리 |
| **검수 및 UI 상태** | `STAGES`, `WORKER_STAGES`, `REVIEWER_STAGES` | 1차/2차/review/final 단계별 정의와 작업자/검수자 권한 분기용 상수 |
| **시각 요소** | `COLORS`, `ISSUE_COLOR`, `PENDING_COLOR`, `FONT` 등 | 바운딩 박스별 클래스 컬러 매핑, 이슈/미지정 박스 색상, 목록 표시 색상 및 맑은 고딕 폰트 설정 |

# 4. 주요 실행 흐름
- 본 파일은 실행 로직 함수를 포함하지 않는 순수 설정 및 상수 정의 모듈이므로, 다른 모듈에서 상수를 임포트하여 초기값이나 분기 조건으로 참조하는 방식으로 동작합니다.

# 5. 확인 및 개선 사항
- 4번 클래스(`고무장갑`)는 `UNUSED_CLASS` 및 `CLASS_IDS` 필터링을 통해 시각적 선택 목록에서는 안전하게 숨기면서 YOLO 모델과의 호환성(인덱스 번호)을 그대로 유지하도록 정교하게 설계되었습니다.
- 크로스 플랫폼(Windows, WSL, Linux) 환경을 모두 고려하여 한글 프리뷰 폰트 경로(`PREVIEW_FONTS`)를 우선순위별로 튜플 형태로 안전하게 확보하고 있습니다.
