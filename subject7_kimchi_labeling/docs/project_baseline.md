# Project Baseline — 조각김치 이물검출 라벨링 프로젝트 (교과 7)

## 개요
900장 조각김치 이미지에서 이물질을 7개 클래스(0~6)로 YOLO 포맷 라벨링(보정 포함)하는 프로젝트의 공통 기준 문서. 팀 전원이 이 기준에 합의한 뒤 작업을 시작한다.

### 3 화면 구성 (확정된 와이어프레임)
- **상단**: 진행률 = (완성된 파일양) / (전체 파일양)
- **좌측**: 사이드바 on/off, 폴더분류란, 폴더내 이미지 목록
- **중앙**: 이미지 작업 영역
- **중앙 하단**: 원상태 / 확대 / 축소 / 삭제
- **우측 상단**: 클래스 분류, 클래스 크기 정보
- **우측 중단**: 자동 라벨링(YOLO), 작성자, 검수상태, 이슈노트, 작업자 정보(1차/2차), 검수자 정보(review-final)
- 우측 하단 : 이전 / 다음 / 저장 / 저장 후 다음

## 5. 라벨 작업 기준
### 검수 체계

| 단계             | 담당자           | 비고                   |
| -------------- | ------------- | -------------------- |
| 1차 라벨 검수       | 김성섭, 김도은, 권지현 | 라벨링 결과를 처음 확인        |
| 교차검수(2차 라벨 검수) | ==#작성필요==     | 1차 검수자와 다른 사람이 다시 확인 |
| REVIEW 최종 판단   | 김성섭           | 판단이 어려운 건을 최종 결정     |

### 데이터 저장 위치

| 구분           | 폴더 경로         | 비고           |
| ------------ | ------------- | ------------ |
| 작업 중 데이터     | `data/work/`  | 라벨링 작업 중인 파일 |
| 최종 QA 완료 데이터 | `data/final/` | QA를 통과한 최종본  |

## 6. Dataset Manifest 항목
| 항목               | 의미                     | 예시                             |
| ---------------- | ---------------------- | ------------------------------ |
| `file_name`      | 이미지 파일명                | `250410_144403911987.jpg`      |
| `source_dataset` | 원래 어느 데이터셋에서 왔는지       | ==`dataset1`, `dataset2`==     |
| `original_split` | 기존 train/validation 위치 | `train`, `validation`          |
| `scene_type`     | 이미지 전체 장면 유형           | ==#작성필요==                      |
| `stage`          | 현재 작업 단계               | `1차`, `2차`,  `review`, `final` |
| `from`           | 불러온 라벨의 출처(이전 단계)      | `raw`,  `1차`                   |
| `boxes`          | 저장한 BBox 개수            | `5`                            |
| `worder_name`    | 작업자 이름                 | `gildong`                      |
| `worker_id`      | 작업자 ID                 | `gildong`                      |
| `reviewer_name`  | 검수자 이름                 | `younghee`                     |
| `reviewer_id`    | 검수자 ID                 | `younghee`                     |
| `issue`          | 이슈/review 사유           | `Y`                            |
| `save_at`        | 저장 시각                  | `2026-10-07 09:43:48`          |

## 7. 완료 기준

| #   | 완료 기준            | 목표          | 확인 방법                                    | 완료  |
