## 1. 공통 원칙

- 사용 Class: 0~6
- 판단이 명확한 객체만 해당 Class로 지정합니다.
- Class 판단이 어려우면 임의 지정 후 이슈노트 작성합니다.
- 김치 자체는 검출 대상 Class가 아닙니다.
- Class 4 고무장갑은 현재 프로젝트에서 사용하지 않습니다.

## 2. 클래스별 라벨링 기준

| 클래스                 | 대상                                  | 포함                                        | 제외                                             | 애매한 경우                                                                                       |
| ------------------- | ----------------------------------- | ----------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **0 — 나뭇잎·종이류**     | 조각김치 사이에서 발견되는 나뭇잎 또는 종이 형태의 객체     | 나뭇잎,  <br>잘린 잎 조각,  <br>종이 조각,  <br>종이 뭉치 | 김치 잎,  <br>파,  <br>고추,  <br>나뭇가지               | 나뭇잎인지 김치 잎인지 명확하지 않으면 REVIEW                                                                 |
| **1 — 플라스틱류·돌·금속류** | 플라스틱, 돌, 금속과 같이 제조 과정에서 이물로 판단되는 객체 | 플라스틱 조각,  <br>비닐 조각,  <br>돌,  <br>금속 조각   | 나뭇가지,  <br>식물성 잎,  <br>파·고추                    | 재질을 이미지로 판단하기 어려우면 REVIEW  <br>돌인지 김치 잎인지 명확하지 않으면 REVIEW  <br>바닥재질인지 이물질인지 판단하기 어려우면 REVIEW |
| **2 — 나뭇가지류**       | 막대 또는 가지 형태의 나무성 이물                 | 나뭇가지,  <br>작은 가지 조각,  <br>줄기 형태의 목질 이물    | 파 줄기,  <br>고추 꼭지, <br>나뭇잎 조각                   | 나뭇가지와 채소 줄기의 구분이 어려우면 REVIEW                                                                 |
| **3 — 벌레류**         | 이미지에서 확인되는 벌레 또는 곤충 형태의 객체          | 벌레,  <br>곤충 형태가 명확한 객체                    | 작은 검은 반점,  <br>김치 양념 덩어리,  <br>형태를 식별할 수 없는 이물 | 벌레인지 단순 얼룩인지 판단하기 어려우면 REVIEW  <br>벌레인지 다른 이물질인지 판단하기 어려우면 REVIEW                            |
| **4 — 고무장갑**        | 현재 사용하지 않음                          | -                                         | -                                              | 기존 TXT에서 Class 4가 발견되면 임의로 삭제하지 않고 REVIEW 처리                                                 |
| **5 — 병해·갈변**       | 식재료에서 확인되는 병해 또는 갈변 형태              | 갈색으로 변색된 부위,  <br>병해로 판단되는 이상 부위          | 정상적인 김치 양념 색상,  <br>그림자  <br>촬영 조명에 의한 색 변화    | 실제 갈변인지 조명 차이인지 판단하기 어려우면 REVIEW  <br>벌레인지 병해인지 이미지로 판단하기 어려우면 REVIEW                        |
| **6 — 파·고추**        | 조각김치 이미지에서 검출 대상으로 지정된 파 또는 고추      | 파 조각,  <br>고추 조각,                         | 김치 잎,  <br>나뭇잎,  <br>나뭇가지                      | 파·고추와 다른 식물 조각을 구분하기 어려우면 REVIEW                                                             |
## 3. 상황별 작업 예시
